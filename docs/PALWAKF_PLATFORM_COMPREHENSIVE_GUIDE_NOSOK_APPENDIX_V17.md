# PalWakf Comprehensive Guide — Nosok Appendix v17

## Governing rule added
For semi-independent systems under PalWakf, operational pages must be data-bound before production gate. Static governance panels are acceptable only as temporary scaffolding.

## Nosok v17 additions
- Workbench must read computed operational buckets.
- Service Desk must search protected administrative indexes, not public tracking.
- Season Command must enforce opening gates before any season-open decision.
- Public tracking remains privacy-limited; admin service-desk search is RBAC-protected.
