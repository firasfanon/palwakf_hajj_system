# ERROR RECORD — Nosok v37A

## ER-V37A-001 — الصفحة العامة عصرية جزئيًا فقط

**السبب:** v37 نظّمت الصفحة العامة لكنها بقيت باهتة بصريًا وبهيكل قريب من بوابة نظام نظيفة.  
**الأثر:** ضعف الانطباع الأول وضعف أولوية CTA الرئيسي.  
**الحل:** تقوية Hero، إضافة Seasonal Banner، إعادة ترتيب البطاقات حسب الأولوية، وتبسيط Navigation.

## ER-V37A-002 — ازدحام الشريط العلوي

**السبب:** عرض معظم المسارات العامة كـ chips مباشرة في الشريط العلوي.  
**الأثر:** كثافة زائدة على desktop واحتمال ازدحام أعلى على mobile.  
**الحل:** إبقاء المسارات الأكثر استخدامًا فقط ونقل الخدمات الثانوية إلى قائمة “المزيد”.

## ER-V37A-003 — لغة بعض البطاقات بقيت إدارية

**السبب:** وجود عبارات مثل سياسة قابلة للتعديل وحالة موسمية بصياغة أقرب للحكومة الداخلية.  
**الأثر:** المواطن يحتاج صياغة مباشرة ومفهومة.  
**الحل:** Citizen-first copywriting مع إبقاء التفاصيل الفنية في لوحة الإدارة.
