# ERROR RECORD — Nosok v27C

## ER-27C-001 — خطر القرعة العامة غير الجغرافية

- **السبب:** القرعة العامة قد لا تحقق عدالة التوزيع حسب التجمعات.
- **الحل:** اعتماد LGU-based quota lottery.
- **الحالة:** مغلق كعقد واجهة/حوكمة.

## ER-27C-002 — خطر اختيار الطلبات دون مراعاة عدد الأشخاص

- **السبب:** طلب واحد قد يحتوي عدة أفراد ويتجاوز حصة التجمع.
- **الحل:** اعتماد capacity-aware draw عبر `totalPeopleCount`.
- **الحالة:** مغلق كعقد واجهة/حوكمة.

## ER-27C-003 — خطر نقل حصة تلقائيًا بين تجمعات

- **السبب:** النقل التلقائي يفتح مشكلة عدالة وشفافية.
- **الحل:** `committee_decision_required` عند عدم استكمال الحصة من نفس LGU.
- **الحالة:** مغلق كقاعدة حاكمة.

## ER-27C-004 — عدم إمكانية تشغيل analyzer داخل الحاوية

- **السبب:** Flutter/Dart SDK غير متاحين في بيئة التنفيذ الحالية.
- **الحل:** توثيق local retest required.
- **آخر baseline مستقر:** Nosok v27B.
