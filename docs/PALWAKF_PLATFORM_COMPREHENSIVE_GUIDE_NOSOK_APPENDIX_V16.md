# PalWakf Governing Guide Appendix — Nosok v16

Nosok v16 adds government user experience and admin productivity surfaces required for a semi-independent system under PalWakf.

## Rules reinforced
- Public surfaces must be service-oriented, not administrative information pages.
- Admin dashboard must be supported by operational workbench and command surfaces.
- Users/RBAC remain platform-owned.
- Unit surfaces remain scoped to `core.org_units` and `nosok.unit_service_scopes` only adjusts Nosok service visibility.
- Visual governance follows PWF-SIS: shared platform identity + system-specific body.
