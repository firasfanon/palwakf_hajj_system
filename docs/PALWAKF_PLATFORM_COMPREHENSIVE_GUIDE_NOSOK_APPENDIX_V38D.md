# PalWakf Guide Appendix — Nosok v38D

## تعريف الدفعة
Nosok v38D يضيف عقدًا تحضيريًا لقدرة نسك على إنشاء صفحات وأقسام مستقبلية دون مطور، مع إبقاء التنفيذ الحقيقي مؤجلًا إلى منصة PalWakf.

## القاعدة
- نسك شبه مستقل: يحتاج أدوات إدارية للمحتوى والصفحات.
- الاستقلالية لا تعني bypass للمنصة.
- الصفحات العامة يمكن إنشاؤها من قوالب آمنة.
- الصفحات الإدارية الجديدة تحتاج RBAC/RPC/RLS ونطاق وحدة.

## لا تنفيذ إنتاجي
لا schema، لا SQL، لا DML، لا backend binding.
