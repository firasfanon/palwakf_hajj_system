# PalWakf Comprehensive Guide Appendix — Nosok v15

Nosok v15 reinforces the semi-independent system contract:

- Public surfaces must be citizen-service-first, not administrative text pages.
- Admin dashboard must be operational and route users to work queues, evidence, billing, privacy, units, and role tests.
- Sidebar inside the system can be grouped and polished, but visibility remains filtered by platform AccessProfile/RBAC.
- Unit pages are scoped service surfaces only. `core.org_units` remains the source of truth.
- Nosok may provide preview-host files for standalone testing, but production is under PalWakf.
- No `legacy.dart` added.
- No waqf/waqf_assets/awqaf_system mutation.
