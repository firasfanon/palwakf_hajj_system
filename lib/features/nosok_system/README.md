# Nosok System

نظام نسك داخل PalWakf هو نظام **mixed public/admin** لإدارة:
- مواسم الحج والعمرة
- البرامج
- الشركات المؤهلة
- الطلبات
- الشكاوى
- المحتوى العام والتعليمات

## ما يملكه
- جداول تشغيلية في schema مستقلة: `nosok`
- صفحات عامة وإدارية خاصة به
- منطق عرض خاص به داخل Body النظام

## ما لا يملكه
- لا يعيد بناء Top Bar / Header / Footer
- لا يعيد تعريف الهوية أو RBAC العامة للمنصة
- لا ينشئ جداول مرجعية مكررة لوحدات المنصة أو الجغرافيا

## الربط
- public routes تحت public shell
- admin routes تحت admin shell
- content system-level عبر slug تقني `nosok` داخل الجداول العامة عند الحاجة
